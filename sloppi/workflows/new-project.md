# Workflow: Greenfield New Project

This workflow guides an agent through building a complete new web application or marketing website from scratch.

---

## Operational Recipe

```
[ Greenfield Workflow ]
        │
        ├──────► STEP 1: Understand (Interrogate product intent, persona, density mode)
        ├──────► STEP 2: Research (Route questions to source-registry.md, curate constellation)
        ├──────► STEP 3: Synthesize (Formulate Design Thesis, establish visual tension)
        ├──────► STEP 4: Content Architecture (Define 7-tier attention budget, real specs)
        ├──────► STEP 5: Design System (Define 25 canonical sections in DESIGN.md)
        ├──────► STEP 6: Scaffolding (Inject 3-tier CSS variables in :root, zero package bloat)
        ├──────► STEP 7: Implementation (Execute 7-pass build order: Skeleton → Tokens → DOM)
        ├──────► STEP 8: Render & Visual QA (Capture Mobile, Tablet, Desktop, Wide)
        ├──────► STEP 9: Anti-Slop Audit (Screen against 26 AI default signals)
        ├──────► STEP 10: Refinement Loop (Prioritize on Impact × Cost, resolve blockers)
        └──────► STEP 11: Ship (Verify 7 stopping criteria, commit DESIGN.md)
```

### Required Artifacts
- `DESIGN.md` (Persistent design system contract).
- Source Code (Components, Sections, Tokens).
