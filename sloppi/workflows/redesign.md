# Workflow: Existing Codebase Redesign

This workflow guides an agent through redesigning an existing frontend application while preserving functioning business logic and adapting to established stack conventions.

---

## Operational Recipe

```
[ Redesign Workflow ]
        │
        ├──────► STEP 1: Inspect Codebase (16-point inspection matrix, identify maturity tier)
        ├──────► STEP 2: Identify Deficiencies (Audit existing page against 26 AI default signals)
        ├──────► STEP 3: Research & Benchmark (Route to source-registry.md for fresh patterns)
        ├──────► STEP 4: Formulate Design Thesis (Author or update project DESIGN.md)
        ├──────► STEP 5: Map Tokens (Integrate new tokens into existing CSS/Tailwind config)
        ├──────► STEP 6: Refactor Content & Hierarchy (Purge buzzwords, tighten narrative)
        ├──────► STEP 7: Refactor Components (Replace generic cards with domain widgets)
        ├──────► STEP 8: Render & Visual Audit (Verify mobile, tablet, and desktop views)
        ├──────► STEP 9: Execute Refinement Loop (Fix regressions, verify keyboard focus)
        └──────► STEP 10: Ship & Document (Record changes in DESIGN.md)
```
