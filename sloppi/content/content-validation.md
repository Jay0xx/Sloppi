# Sloppi Content Validation & Anti-Slop Content Audit

The Content Validation protocol is an evidentiary verification gate that coding agents must execute before writing any frontend UI markup or CSS tokens.

If a page's content architecture is fundamentally flawed, writing HTML and CSS will merely produce visually polished slop. This protocol ensures that all content is truthful, specific, narratively progressive, and architecturally justified.

---

## 1. The 11-Point Content Pre-Implementation Checklist

Before committing to code generation, the agent must evaluate the content plan against eleven verification filters:

```
┌────────────────────────────────────────────────────────────────────────┐
│              THE 11-POINT CONTENT VALIDATION CHECKLIST                 │
│                                                                        │
│ 1. [ ] PRIMARY ASSERTION CLARITY                                       │
│    Is the single most important message immediately clear within 3s?   │
│                                                                        │
│ 2. [ ] PAGE GOAL SINGULARITY                                           │
│    Does the page guide the user toward an unambiguous primary action?  │
│                                                                        │
│ 3. [ ] SECTION JUSTIFICATION COMPLIANCE                                │
│    Has every proposed section passed the 6-part justification test?    │
│                                                                        │
│ 4. [ ] ABSOLUTE TRUTHFULNESS & ZERO FABRICATION                        │
│    Are all logos, quotes, performance metrics, and SLAs 100% real?     │
│                                                                        │
│ 5. [ ] VOCABULARY SPECIFICITY                                          │
│    Have all empty buzzwords (supercharge, revolutionize, seamless)     │
│    been purged in favor of plain technical verbs and domain nouns?     │
│                                                                        │
│ 6. [ ] INTENTIONAL ATTENTION HIERARCHY                                 │
│    Is there clear mathematical and visual separation across the 7 tiers│
│    rather than Equal Loudness Syndrome?                                │
│                                                                        │
│ 7. [ ] OUTCOME-EXPLICIT CTAS                                           │
│    Do all button labels state the exact consequence of clicking?       │
│                                                                        │
│ 8. [ ] REPETITION & FATIGUE CONTROL                                    │
│    Have consecutive identical card layouts and repeated CTA banners    │
│    been eliminated?                                                    │
│                                                                        │
│ 9. [ ] COHERENT NARRATIVE PROGRESSION                                  │
│    Does each section build logically on the preceding chapter?         │
│                                                                        │
│ 10. [ ] COMPOSITIONAL ALIGNMENT                                        │
│     Does the physical layout (matrix, terminal, diff) directly reflect │
│     the content's structural nature rather than a generic box?         │
│                                                                        │
│ 11. [ ] ZERO FILLER CONTENT                                            │
│     Has all placeholder text, artificial box padding, and decorative   │
│     statistics been deleted?                                           │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. The 12 Anti-Slop Content Audit Flags

During content review, the agent scans for 12 common failure flags. Detecting any flag triggers immediate copy and structural refinement:

```
[ Content Review & Critique ]
        │
        ├──────► FLAG 1: Generic Headline ("The ultimate platform for modern teams")
        ├──────► FLAG 2: Vague Marketing Adjectives (Supercharge, seamless, elevate, empower)
        ├──────► FLAG 3: Fake Metrics ("99.9% faster", "10x productivity" without benchmark data)
        ├──────► FLAG 4: Fabricated Social Proof (Unverifiable quotes, fake avatars, unauthorized logos)
        ├──────► FLAG 5: Monotonous CTA Copy (Repeating "Get Started" 8 times down the page)
        ├──────► FLAG 6: Unjustified Filler Sections (Adding an FAQ with 2 obvious questions to pad space)
        ├──────► FLAG 7: Template-Like Section Sequence (Hero → Logos → 3 Cards → Testimonials → Pricing → CTA)
        ├──────► FLAG 8: Filler Copy (Writing 4 sentences when 1 sentence conveys the idea)
        ├──────► FLAG 9: Exhaustive Feature Bloat (Listing 30 trivial settings instead of 3 differentiators)
        ├──────► FLAG 10: Meaningless Badges (Pills reading "AI-Powered", "#1 Tool" with no proof)
        ├──────► FLAG 11: Unlabeled Data Visualizations (Graphs with no axes, units, or data sources)
        └──────► FLAG 12: Universal Card Reflex (Wrapping every single concept in a rounded box)
```

### Remediation Protocol by Flag

| Detected Flag | Root Cause | Sloppi Mandatory Remediation |
| :--- | :--- | :--- |
| **FLAG 1: Generic Headline** | Lack of technical understanding | Replace with specific mechanism + concrete outcome (*"Lock-free cache engine with sub-millisecond p99 latency"*). |
| **FLAG 3: Fake Metrics** | Marketing insecurity | Provide reproducible benchmark script parameters or remove metric entirely. |
| **FLAG 4: Fabricated Social Proof** | Artificial credibility attempt | Replace with technical architecture diagrams, live REPLs, or open-source repo links. |
| **FLAG 7: Template Sequence** | Relying on AI web defaults | Re-sequence chapters along the 9-stage cognitive narrative arc tailored to user friction. |
| **FLAG 12: Universal Card Reflex** | Lazy component selection | Map content to optimal representation (e.g. data matrix, terminal CLI, annotated diagram). |

## 3. Content Audit Output Schema

When the agent validates content, it records its findings in the project research log or `DESIGN.md` rationale section:

```markdown
### Sloppi Content & Composition Audit Log

- **Audit Status**: [APPROVED | REFINEMENT REQUIRED]
- **Checked Items**: [11/11 Passed]

#### Identified Flags & Remediation Actions
1. **Flag Identified**: [e.g., FLAG 1: Generic Headline in Hero]
   - *Original Copy*: "Revolutionize your database workflow with AI"
   - *Remediation*: "Automated PostgreSQL schema migration rollback with zero table locks"
2. **Flag Identified**: [e.g., FLAG 4: Unverified Testimonial Section]
   - *Original Content*: 3 fake testimonial cards with stock avatar photos.
   - *Remediation*: Deleted testimonial cards; replaced with an annotated SVG architecture dataflow diagram and GitHub commit telemetry.
3. **Flag Identified**: [e.g., FLAG 5: Monotonous CTA Copy]
   - *Original Copy*: "Get Started" repeated 6 times.
   - *Remediation*: Replaced with contextual outcome labels: "Create Free Workspace", "Inspect TypeScript SDK", and "Deploy PostgreSQL Cluster".

- **Narrative Progression Assessment**: [1-sentence validation confirming that the page progresses logically from technical friction to verifiable proof to decisive action].
```
