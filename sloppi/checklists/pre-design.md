# Sloppi Agent Checklist: Pre-Design

Execute this checklist before defining the design system or authoring `DESIGN.md`.

---

```markdown
## Pre-Design Checklist

- [ ] **1. Product Intent Understood**: Core operational stakes, user mental model, and primary conversion action identified.
- [ ] **2. Audience Calibrated**: Density mode selected (Sparse vs. Moderate vs. Dense HUD) based on user workflow.
- [ ] **3. Research Questions Formulated**: High-intent inquiries routed to targeted galleries in `source-registry.md`.
- [ ] **4. Reference Constellation Curated**: 3–5 diverse references selected for distinct structural roles (not copied whole).
- [ ] **5. Transferable Principles Extracted**: Mathematical type ratios, spatial baselines, and layout paradigms isolated.
- [ ] **6. Design Thesis Formulated**: Controlled visual tension defined (e.g. "Tungsten Precision + Phosphor Telemetry").
- [ ] **7. Content Architecture Validated**: 7-tier Attention Budget established; Section Justification test executed.
```
