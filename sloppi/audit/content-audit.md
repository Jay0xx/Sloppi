# Sloppi Content & Truthfulness Audit

The Content Audit inspects rendered copywriting, product claims, metrics, and call-to-action labeling to ensure the interface communicates domain-specific truth rather than generic marketing slop.

---

## 1. The 6-Point Content Audit Checklist

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. PURGED MARKETING CLICHÉS    ──► Zero ungrounded buzzwords           │
│                                    (supercharge, revolutionize, next-gen│
│ 2. FALSIFIABLE TECHNICAL CLAIMS──► Explains the architectural mechanism│
│                                    (io_uring, CDC, lock-free ring).    │
│ 3. ABSOLUTE PROOF INTEGRITY    ──► 100% authentic customer quotes,     │
│                                    authorized logos, and real metrics. │
│ 4. OUTCOME-EXPLICIT CTAS       ──► Action buttons declare consequences │
│                                    ("Create Free Workspace", "Deploy").│
│ 5. ZERO PLACEHOLDER COPY       ──► Zero "Lorem ipsum" or filler text.  │
│ 6. CONSISTENT DOMAIN TERMINOLOGY─► Vocabulary matches audience profile │
│                                    (DevOps vs. Treasury vs. Horology). │
└────────────────────────────────────────────────────────────────────────┘
```

---

## 2. Content Deficiency Catalog & Fixes

| Content Flaw | Diagnostic Symptom | Severity | Sloppi Remediation |
| :--- | :--- | :--- | :--- |
| **Fabricated Social Proof** | Section features 3 fake customer cards (*"Sarah J., VP TechCorp"*) with stock avatars. | **BLOCKER** | Delete fake testimonials; replace with an annotated SVG architecture dataflow or open-source repo link. |
| **Unsubstantiated Metric** | Headline asserts *"10x faster developer velocity"* with zero benchmark context. | **HIGH** | Replace with concrete benchmark data (*"p99 read latency < 450μs on AWS c6i.16xlarge"*). |
| **Monotonous Generic CTAs** | Button label reads *"Get Started"* repeated 8 times down the entire page. | **MEDIUM** | Replace with contextual outcome labels (*"Deploy PostgreSQL Cluster"*, *"Read Documentation"*). |
| **Vague Adjective Stacking** | Subhead reads: *"A powerful, seamless, modern, intelligent all-in-one platform."* | **MEDIUM** | Replace with concrete technical capability (*"Multi-threaded cache engine with native NVMe tiering"*). |
| **Leftover Placeholder Copy** | Card contains `"Lorem ipsum dolor sit amet"` or `[Add feature text here]`. | **HIGH** | Populate with domain-specific feature explanation or temporary wireframe token. |
