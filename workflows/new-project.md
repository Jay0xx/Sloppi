# Workflow: Greenfield New Project (Sloppi v2.0)

This workflow guides an agent through designing and building a complete new web application or landing page with **bold art direction, 3-direction creative divergence, and visual-first verification**.

---

## Operational Recipe (8-Stage Creative Director Loop)

```
[ Greenfield Workflow v2.0 ]
        │
        ├──────► STAGE 1: Interrogate & Inspect Live References
        │                 • Identify persona, 5-second interactive goal, & category clichés to subvert.
        │                 • Inspect 2–4 references (`awwwards.com`, `godly.website`, `minimal.gallery`,
        │                   `60fps.design`, `dribbble.com`, `saaspo.com`) and log concrete observations.
        │
        ├──────► STAGE 2: Diverge into 3 Distinct Creative Directions (A vs. B vs. C)
        │                 • Formulate 3 orthogonal concepts differing in spatial layout, font pairing,
        │                   surface materiality, and interactive centerpiece ([doctrine/creative-direction.md]).
        │
        ├──────► STAGE 3: Pass the Originality Gate & Lock `DESIGN.md`
        │                 • Reject any direction that looks like a generic SaaS template OR a flat
        │                   `1px`-bordered wireframe / standard dark-green CLI terminal.
        │                 • Author the streamlined 10-section `DESIGN.md` contract.
        │
        ├──────► STAGE 4: Prototype Primary Composition First
        │                 • Load expressive web fonts (never default to `Inter`) & `:root` tokens.
        │                 • Build the above-the-fold Hero / Core Interactive Workspace first.
        │
        ├──────► STAGE 5: Live Browser Visual Proof Gate (MANDATORY!)
        │                 • Start dev server, inspect live browser render, capture screenshot.
        │                 • Verify typographic scale, materiality, and 5-second interactive hook.
        │                 • Fix any visual flatness BEFORE building remaining sections.
        │
        ├──────► STAGE 6: Scale Full Interface & Bespoke Mechanics
        │                 • Build remaining chapters/screens modulating layout structure, ground tone,
        │                   and spring-physics choreography (`motion`).
        │
        ├──────► STAGE 7: Multi-Viewport QA & 30-Signal Anti-Slop Audit
        │                 • Verify `390px` Mobile, `768px` Tablet, and `1280px+` Desktop viewports.
        │                 • Run Dual Integrity & Materiality Test ([audit/anti-slop-audit.md]).
        │
        └──────► STAGE 8: Screenshot Regression Verification & Ship
                          • Compare Before/After screenshots on any refinements, verify zero console/build
                            errors, sync `DESIGN.md`, and present to user.
```

### Required Artifacts
- `DESIGN.md` (10-section Creative Direction & Design System contract).
- Production Source Code (Expressive Fonts, Semantic Tokens, Interactive Components).
