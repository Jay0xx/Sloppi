# Sloppi Page Narrative & Compositional Flow

Narrative Intelligence teaches coding agents to treat a webpage as a **deliberate progression of ideas**, not a static inventory of accumulated components.

A high-converting, intellectually coherent interface guides the user through an intentional cognitive arc. Each section must establish a compelling reason for the reader to continue, systematically dismantling skepticism, proving technical capability, and building decisive conviction.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        THE PROGRESSION RULE                            │
│                                                                        │
│ "A page must progress logically toward a decision, rather than merely  │
│  accumulating standard website components."                            │
└────────────────────────────────────────────────────────────────────────┘
```

---

## 1. The 9-Stage Cognitive Narrative Arc

Sloppi structures page progression across a flexible 9-stage narrative framework. The agent selects, orders, and modulates only the stages necessary for the product's decision complexity:

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. ENTRY             ──► Immediate visual & conceptual hook in first   │
│                          viewport (high signal, zero clutter).         │
│ 2. ORIENTATION       ──► Clarifying what the product is, who it is     │
│                          for, and what domain it operates in.          │
│ 3. THE FRICTION      ──► Articulating the painful architectural or     │
│                          operational bottleneck in existing workflows. │
│ 4. THE MECHANISM     ──► Introducing the technological breakthrough    │
│                          that resolves the bottleneck.                 │
│ 5. DEMONSTRATION     ──► Proving the mechanism with live interaction,  │
│                          interactive REPL, or high-fidelity UI.        │
│ 6. EVIDENTIARY PROOF ──► Delivering hard verification (benchmarks,     │
│                          architecture diagrams, audit certifications). │
│ 7. DIFFERENTIATION   ──► Explicitly contrasting against traditional    │
│                          legacy alternatives.                          │
│ 8. OBJECTION REMOVAL ──► Addressing migration friction, pricing        │
│                          transparency, and lock-in anxieties.          │
│ 9. DECISIVE ACTION   ──► High-contrast, outcome-explicit conversion    │
│                          closure.                                      │
└────────────────────────────────────────────────────────────────────────┘
```

### Contextual Narrative Truncation
Not every page requires all 9 stages:
- **Developer CLI Tool**: `Entry (Terminal)` $\longrightarrow$ `Mechanism (io_uring)` $\longrightarrow$ `Proof (Benchmarks)` $\longrightarrow$ `Action (npm install)`.
- **Luxury Timepiece**: `Entry (Macro Photo)` $\longrightarrow$ `Orientation (Manufacture Heritage)` $\longrightarrow$ `Mechanism (Escapement Craft)` $\longrightarrow$ `Action (Private Boutique Inquiry)`.
- **Enterprise Fintech**: Full 9-stage progression required to satisfy security, compliance, integration, and fiscal stakeholders.

## 2. The 4-Part Visual Narrative Matrix

For every proposed chapter in the page narrative, the agent must evaluate the intersection of copy, visual art direction, and user cognition:

```markdown
### Visual Narrative Step: [Chapter Name]
1. **WHAT IS THE USER READING?** (Exact headline, subhead, and technical parameters).
2. **WHAT IS THE USER SEEING?** (Layout container, interactive widget, diagram, or whitespace).
3. **WHAT IS THE USER UNDERSTANDING?** (The cognitive takeaway and belief shift).
4. **WHAT IS THE USER EXPECTED TO DO?** (Interact with a control, scroll to next chapter, or click CTA).
```

### Visual-to-Narrative Alignment Rules
- **Visual Weight must match Narrative Weight**: If a section introduces the product's core technological differentiator, it must not be tucked into a tiny bullet point inside a secondary card. It must be given dominant visual hierarchy (e.g. a full-bleed interactive demonstration).
- **Decorative Elements must never overshadow Narrative Truth**: If an animated 3D visualizer distracts from understanding how the database migration works, remove the 3D graphic.

## 3. Section Rhythm & Modulation (6 Levers)

A webpage where every section has identical height ($600\text{px}$), identical padding ($64\text{px}$), identical 3-column grids, and identical gray backgrounds induces rapid reader fatigue and cognitive blindness.

To maintain active engagement, Sloppi deliberately modulates sections across six dimensions:

| Dimension | Modulation State A (Dense / Intense) | Modulation State B (Calm / Spacious) |
| :--- | :--- | :--- |
| **1. Vertical Height** | Compact ($280\text{px}–380\text{px}$) data matrix | Deep ($700\text{px}–900\text{px}$) interactive canvas |
| **2. Spatial Density** | High-density 4px grid telemetry HUD | Generous 128px macro-whitespace editorial quote |
| **3. Ground Color** | Base Canvas (`--color-canvas`) | Elevated Ground (`--color-canvas-alt`) |
| **4. Alignment** | Left-aligned asymmetric technical breakdown | Centered high-impact action closure |
| **5. Layout Structure** | Asymmetric bento grid | 2-column side-by-side code walkthrough |
| **6. Media Texture** | Clean SVG vector architecture diagram | Monospaced dark terminal emulator with code syntax |

## 4. Repetition Control: Useful vs. Accidental

Sloppi enforces a strict distinction between intentional systemic consistency and lazy template repetition:

```
┌────────────────────────────────────────────────────────────────────────┐
│ USEFUL REPETITION (Systemic Consistency — RETAIN)                      │
│ - Consistent typographic scale ratios across all headings.             │
│ - Uniform button geometry, padding, and micro-interaction timings.     │
│ - Consistent semantic color roles (brand color always signaling action)│
├────────────────────────────────────────────────────────────────────────┤
│ ACCIDENTAL REPETITION (Template Slop — ELIMINATE)                      │
│ - Stacking four consecutive sections of identical 3-column cards.     │
│ - Repeating the exact same generic CTA button ("Get Started") 8 times. │
│ - Repeating identical pill badges above every single section heading.  │
│ - Using the same icon size and rounded box container for all content.  │
└────────────────────────────────────────────────────────────────────────┘
```

## 5. Design Tension & Content Composition

Content composition should directly reinforce the project's **Design Thesis tensions** (established in research synthesis):

- **Dense Information + Restrained Visuals**: Use high-density monospaced data grids paired with calm, monochrome surfaces and razor-sharp 1px borders.
- **Serious Product + Warm Language**: Ground high-stakes financial operations with clear, human, reassuring explanations and unhurried editorial whitespace.
- **Technical Mechanism + Editorial Composition**: Present complex distributed systems architecture with elegant book-like typography, wide margins, and annotated linework.
- **Minimal Interface + Expressive Typography**: Eliminate decorative cards and icons entirely; allow oversized, perfectly balanced display headlines to carry the visual authority.
