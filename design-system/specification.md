# Sloppi DESIGN.md Specification

A `DESIGN.md` file is a project-specific, persistent design contract for coding agents. It provides unambiguous, AI-readable design context before implementation begins, ensuring that all subsequent UI generation adheres to a unified visual thesis.

Refero Styles research demonstrates that coding agents generate superior, consistent interfaces when design context:
1. Exists **before** code generation, rather than being applied as a reactive cleanup step.
2. Combines **exact numerical tokens** with **human-readable rationale**.
3. Employs **semantic roles** so agents understand the functional purpose of every value rather than memorizing raw numbers.
4. Includes explicit **Do / Don't guardrails**.

---

## Required Sections in Every Sloppi `DESIGN.md`

Every `DESIGN.md` generated by a Sloppi-enabled agent must contain the following 14 core sections:

```markdown
# [Product Name] — Design System Specification

## 1. Design Thesis
- A concise 1-2 sentence visual point of view and material metaphor.
- Explains the aesthetic direction, density model, and emotional tone.

## 2. Brand Personality & Archetype
- 3 to 5 key tonal attributes (e.g., "Industrial, Calm, Precise, High-Contrast").
- Target audience mental model and operational stakes.

## 3. Typography Architecture
- Display Typeface: Family, weights, optical usage, fallbacks.
- Body/UI Typeface: Family, weights, letter-spacing rules, fallbacks.
- Monospace Typeface: Family, tabular alignment rules.
- Type Scale: Mathematical scale ratio (e.g., Minor Third 1.200), exact pixel/rem sizes, line-height proportions, letter-spacing values, and semantic assignment (hero, display, h1, h2, h3, body-lg, body, body-sm, caption, code).
- Typographic Rationale: Why these typefaces and leading values were chosen.

## 4. Color Palette & Semantic Roles
- Canvas / Ground: Base background color(s) and alternates.
- Foreground / Text: Primary, secondary, muted, and inverse text colors with WCAG contrast verification.
- Brand Signature: Primary brand anchor color and hover/active variants.
- Accent Palette: Functional and semantic accent colors (e.g., warning, success, info, highlight) with explicit usage descriptions.
- Borders & Dividers: Line colors and opacity levels.
- Surface & Card Tints: Subtle background fills for containers.

## 5. Spacing & Density System
- Base Unit: 4px or 8px grid baseline.
- Spacing Scale: Step values (2, 4, 8, 12, 16, 24, 32, 48, 64, 96, 128px).
- Layout Density: Max container width, section padding (vertical/horizontal), card padding, element gap.

## 6. Shape, Geometry & Border Radii
- Radii Scale: Mapped to element hierarchy (e.g., tags: 4px, buttons: 6px, cards: 12px, dialogs: 16px, pills: 9999px).
- Border Logic: Stroke width (1px vs 2px), style (solid vs dashed), and container containment rules.

## 7. Elevation, Shadows & Depth
- Elevation Levels: 0 (flat/flush), 1 (subtle card elevation), 2 (dropdown/popover), 3 (modal dialog).
- Shadow Recipes: Multi-layered, low-opacity ambient shadows vs. crisp hard borders.
- Surface Lighting: Ambient gradients or backdrops (if justified by thesis).

## 8. Component Guidelines
- Buttons: Primary, secondary, ghost, destructive, outline styles with hover/active/focus-visible states.
- Inputs & Controls: Focus rings, error borders, label placement, disabled styling.
- Cards & Containers: When to use borders vs. background fills vs. pure whitespace.
- Badges & Status Indicators: Semantic color pairing and minimal typography.

## 9. Navigation & Wayfinding
- Navigation Pattern: Sticky header / floating pill / sidebar dock / mega menu.
- Link Density & Hierarchy: Primary routes vs. utility actions (auth, theme switcher, search).
- Mobile Navigation: Responsive transformation (drawer, bottom sheet, tab bar).

## 10. Imagery, Icons & Media
- Icon System: Icon library (e.g., Lucide, Phosphor), stroke width (1.5px vs 2px), sizing standards.
- Media Treatment: Aspect ratios, corner clipping, borders, captions, hover zoom mechanics.
- Illustrations & Motifs: Brand geometric motifs, diagrams, screenshot framing.

## 11. Motion & Micro-Interactions
- Duration Standards: Micro-interactions (100–150ms), Structural transitions (200–300ms), Major views (350–500ms).
- Easing Curves: Standard ease-out (`cubic-bezier(0.16, 1, 0.3, 1)`), spring physics.
- Reduced Motion: Fallback behavior for `prefers-reduced-motion`.

## 12. Responsive Adaptation Rules
- Breakpoint Spectrum: Mobile (<640px), Tablet (640–1024px), Desktop (1024–1440px), Ultrawide (>1440px).
- Layout Transformations: How complex multi-column grids convert to mobile-native narrative sequences.
- Touch Ergonomics: Minimum 44x44px hit targets and thumb-zone accessibility.

## 13. Accessibility & Usability Standards
- Contrast Ratios: Minimum 4.5:1 for normal text, 3:1 for large text and UI components.
- Keyboard Navigation: Visible, high-contrast `:focus-visible` outlines on all interactive elements.
- Semantic HTML: Heading hierarchy (single H1 per page), landmark elements, ARIA labels.

## 14. Explicit Do's and Don'ts
- Clear, unambiguous guardrails specific to this project to prevent regression into generic defaults.
```
