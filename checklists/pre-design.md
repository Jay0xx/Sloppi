# Sloppi v2.0 Agent Checklist: Pre-Design & Originality Gate

Execute this gate before locking in `DESIGN.md` or writing component code.

---

```markdown
## Pre-Design & Originality Gate Checklist (v2.0)

- [ ] **1. Product & Category Clichés Interrogated**: Core user persona, 5-second interactive goal, and the exact category clichés to subvert (both Gen-1 AI slop and Gen-2 wireframe clichés) are identified.
- [ ] **2. Question-Routed Live References Logged (Zero Name-Dropping)**: Routed by design question ([research/source-routing.md](../research/source-routing.md)), opened actual examples/clips (`typewolf.com`, `unsection.com`, `spottedinprod.com`, `hoverstat.es`, `deadsimplesites.com`, `cosmos.so`, `eyecannndy.com`, `designeng.tools` $\rightarrow$ original source, interactive demos), and recorded deep links, observed behavior/composition, trigger/moves/anchored/settles (for motion), `[INFERRED]` tags, adaptable principle, and product fit—or marked `OFFLINE_SYNTHESIS` / `INACCESSIBLE` fallback.
- [ ] **3. Three Orthogonal Directions Generated (A vs. B vs. C)**: Formulated 3 distinct directions making different choices about **composition, typography, and interaction** (including quiet hierarchy/spacing options vs. motion-led directions naming the exact product moment for feedback, orientation, or continuity).
- [ ] **4. First-Reflex & Self-Plagiarism Test Passed**: Rejected any direction that repeats default LLM habits (`Inter` + `JetBrains Mono`, `#0b0d13` + `#00d084` CLI terminal, or `#ffffff` + `#102A56` flat `1px`-bordered boxes).
- [ ] **5. Expressive Font Pairing Selected**: Chosen a distinctive Display/Serif/Grotesque + UI + Monospace pairing with fluid `clamp()` scale contrast.
- [ ] **6. Materiality & Lighting Recipe Defined**: Defined how surfaces achieve tactile depth (paper grain, specular `1px` top bevels, recessed wells, or bold chromatic blocks) so the page never looks like a flat wireframe.
- [ ] **7. Primary Moment & Effect Contract Specified**: Quiet directions prove clarity through typography/spacing; motion-led directions specify intended behavior, stack fit, dependency/license check, trigger, end state, touch, keyboard, repeated activation, and reduced motion.
```
